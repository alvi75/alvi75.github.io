Parameter-Efficient Multi-Task Fine-Tuning in Code-Related Tasks

Investigating QLoRA fine-tuning across code generation, summarization, and translation

This work presents the first comprehensive evaluation of Multi-task QLoRA across code generation, translation, and summarization, examining both functional correctness and code quality with Qwen2.5-Coder models (0.5B, 1.5B, 3B). Multi-task QLoRA achieves competitive performance versus Single-task QLoRA while training a unified model.

Key findings include:

  • 32.07% Java pass@1 versus 29.89% Single-task (+2.18 points)
  • 29.90% Python summarization BLEU versus 23.31% (+28.3% relative)
  • 32.0% lower Python complexity and 6.3% fewer Java PMD violations at 3B
  • Larger models demonstrate superior ability to balance multiple objectives within QLoRA's parameter-efficient framework
